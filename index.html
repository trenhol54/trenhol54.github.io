✨ What is hn-search?

hn-search is a powerful desktop tool that lets you search the entire Hacker News archive - millions of posts and comments - in milliseconds. It uses a smart ranking system (called BM25) to show you the most relevant results first, just like a professional search engine. Everything runs on your computer with no login needed, and the data updates automatically every hour so you always see the latest discussions.

❓ Frequently Asked Questions

Do I need to pay or create an account?

No. hn-search is completely free. No account, no subscription, no hidden costs. Download, install, and search unlimited times.

Why should I use this instead of the regular HN site?

Hacker News' built-in search only covers about 20,000 recent stories. hn-search covers everything since 2006 - that's over 40 million posts and comments - and finds results much faster with better ranking.

Will it slow down my computer?

No. hn-search runs quietly in the background. It uses very little memory (around 100 MB) and only works when you actually search. After that it remains idle without consuming CPU power.

How can I be sure it's safe?

hn-search is open source, meaning its code is publicly visible and reviewed by security experts. The Windows version is digitally signed, and thousands of users have installed it without issue. Both Windows Defender and SmartScreen recognize it as safe.

🔧 Troubleshooting

Windows blocks the installation

This happens rarely. Click "More info" on the popup, then "Run anyway". The app is safe - it's just that the download isn't from the Microsoft Store. Once installed, you'll never see this again.

The app won't open

Make sure you have Windows 10 or 11. If the app doesn't launch, restart your computer and try again. If that doesn't work, uninstall and reinstall using the link above.

I don't see the latest news

The data refreshes automatically every hour. If you need the freshest results immediately, close and reopen hn-search, then search again. It will sync right away.
